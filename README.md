# 예산과 작업기록

지원사업의 **예산·지출·증빙 위치·작업일지**를 한곳에 기록하는 템플릿입니다.

모두의 AI 실험실에서 사용하던 작업 흐름을 일반용으로 정리했습니다. 개인 지출·영수증·작업 내역은 포함하지 않았습니다.

## 사용

```sh
python -m http.server 8000
```

http://localhost:8000 에서 프로젝트명과 예산을 입력하고 지출·작업일지를 추가하세요.

- 지출 합계, 남은 예산, 증빙 미확인 건수
- 지출과 일지의 추가·수정·삭제
- 지출 CSV, 전체 JSON 백업·복원, 인쇄/PDF

가입·API 키·외부 라이브러리가 필요 없습니다. 기록은 브라우저에 저장됩니다. 증빙 파일 자체는 저장하지 않고 파일명과 위치를 기록합니다. 브라우저 데이터를 지우기 전 JSON 백업을 내려받으세요.

비용 인정 여부를 자동 판정하지 않습니다. 각 지원사업의 규정과 제출 양식을 확인하세요. 원래 사이트의 OCR·공식 제출서식 자동생성은 이 간단한 공개본에 포함하지 않았습니다.
