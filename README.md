# 예산과 작업기록 · Geulbom Lab

**AI 실험은 즐겁게, 지출과 작업기록은 한곳에.**

모두의 AI 실험실 참여 과정에서 사용한 작업 흐름을 바탕으로 만든 **지원사업 예산·작업일지 관리 도구**입니다. 프로젝트 예산을 정하고, 지출과 증빙 위치를 기록하고, 날짜별 작업 내용을 정리할 수 있습니다.

누구나 자신의 프로젝트에 사용할 수 있도록 정리한 **공개용 기본 버전**입니다. 개인 지출·영수증·작업 내역은 포함하지 않았습니다.

## 실행 방법

**이 GitHub 화면은 코드와 설명을 보는 곳입니다.** 실제 입력 화면은 웹사이트를 열거나 컴퓨터에서 실행해야 나타납니다.

웹사이트 공개는 저장소의 [Settings → Pages](https://github.com/geulbom-lab/project-budget/settings/pages)에서 설정합니다.

1. Source: `Deploy from a branch`
2. Branch: `main`, 폴더: `/(root)`
3. `Save`를 누르고 배포 완료를 기다립니다.

**배포 완료 후 사용할 주소:** https://geulbom-lab.github.io/project-budget/

주소가 열리지 않으면 Pages 설정과 배포 완료 여부를 확인하세요. 코드를 올리는 것만으로 웹사이트가 자동으로 열리지는 않습니다.

## 현재 사용할 수 있는 기능

| 기능 | 내용 |
| --- | --- |
| 프로젝트 설정 | 프로젝트명·총예산 입력 |
| 예산 확인 | 지출 합계·남은 예산·증빙 미확인 건수 |
| 지출 관리 | 날짜·분류·사용처·금액·사용 목적 입력 및 수정·삭제 |
| 증빙 관리 | 파일명·보관 위치 기록, 확인 완료 표시 |
| 작업일지 | 날짜·작업시간·목표·실제로 한 일·결과와 다음 할 일 기록 |
| 내보내기 | 지출 CSV 다운로드, 화면 인쇄 또는 PDF 저장 |
| 백업·복원 | 전체 기록을 JSON 파일로 저장하고 다시 불러오기 |

## 사용 순서

1. **프로젝트명과 총예산**을 입력하고 설정을 저장합니다.
2. **지출 기록**에 금액·사용 목적·증빙 위치를 적습니다.
3. **작업일지**에 실제로 한 일과 결과를 기록합니다.
4. **CSV 내려받기** 또는 **인쇄 / PDF**로 필요한 자료를 저장합니다.
5. **백업 저장**으로 전체 기록을 보관합니다.

가입·API 키·외부 라이브러리가 필요 없습니다. 기록은 **입력한 기기의 해당 브라우저**에 저장되며 다른 기기와 자동 동기화되지 않습니다. 기기를 옮기거나 브라우저 데이터를 지우기 전 JSON 백업을 저장하세요.

## 원래 작업 사이트와의 차이

- 증빙 파일 자체는 첨부·저장하지 않고 **파일명과 보관 위치**를 기록합니다.
- **영수증 OCR·공식 제출서식 자동생성**은 이 공개본에 포함되어 있지 않습니다.
- 인쇄/PDF는 화면 출력 기능이며, 지원사업 공식 제출서식 생성 기능이 아닙니다.
- 비용 인정 여부와 지원 한도를 자동 판정하지 않습니다. 해당 지원사업의 지침과 제출 양식을 확인하세요.

모두의 AI 실험실 운영기관이 제공하는 공식 서비스가 아닌, 참여 경험을 바탕으로 만든 **개인 제작 비공식 도구**입니다.

## 컴퓨터에서 직접 실행하기

Python이 설치된 컴퓨터에서 저장소를 내려받고 압축을 푼 뒤, `index.html`이 있는 폴더에서 실행합니다.

```sh
python -m http.server 8000
```

서버를 켠 **같은 컴퓨터**의 브라우저에서 http://localhost:8000 을 엽니다. 이 주소는 다른 사람에게 공유하는 웹사이트 주소가 아닙니다.

## 개발 검증

Node.js가 설치되어 있다면 다음 명령으로 테스트할 수 있습니다.

```sh
node --test test.cjs
```
